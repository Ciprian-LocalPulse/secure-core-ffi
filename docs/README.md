`security-core-ffi` is an authenticated encryption core (AES-256-GCM), written in Rust for memory safety and exposed through a stable C interface (FFI), so the same security logic can be reused identically from C++, Python, Node.js, and any other language capable of linking a C dynamic library.

`security-core-ffi` este un nucleu de criptare autentificată (AES-256-GCM), scris în Rust pentru siguranța memoriei și expus printr-o interfață C stabilă (FFI), astfel încât aceeași logică de securitate să poată fi reutilizată identic din C++, Python, Node.js și orice alt limbaj capabil să lege o bibliotecă dinamică C.
