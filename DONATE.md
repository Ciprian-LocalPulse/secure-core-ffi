# Support this project

**security-core-ffi** is written, maintained, and documented by **Ciprian Ștefan Pleșca**, an independent researcher, without institutional funding, corporate backing, or academic grants.

## Why donations matter here

Most open-source cryptographic tooling that reaches a level of polish comparable to commercial software is built by teams with salaries, employers, or research grants behind them. This project is built differently: by one person, on personal time, alongside the ordinary costs of living and working — with no funding source covering that time.

That doesn't change the standard the work is held to. The architecture is documented, the threat model is stated explicitly, and the code is public specifically so that anyone can verify it rather than take it on faith. What it does mean is that continuing to maintain this project — fixing issues, extending the documentation, reviewing integration questions, eventually pursuing an independent security audit — depends entirely on time that has to come from somewhere.

If this project has saved you time, taught you something, or become part of a system you rely on, a donation is a direct way to make continuing that work more sustainable.

## What donations go toward

- Time spent maintaining the codebase and responding to issues and integration questions.
- Infrastructure costs (CI, hosting for documentation, testing across platforms).
- Working toward an independent third-party security review, which is currently listed as an unmet limitation in the [whitepaper](WHITEPAPER.md) — this is the single highest-value use of any funding this project receives.

## What a donation is not

A donation does not purchase support priority, influence over the roadmap, or a say in design decisions — those remain driven by what is judged technically correct, not by who has contributed. It also is not a purchase of a product, a paid license, or a tax-deductible charitable contribution; it is a voluntary gift to an individual maintainer.

## Other ways to help

Money isn't the only form of support that matters. Opening well-described issues, contributing a language binding, improving the documentation, or simply pointing out a flaw in the threat model is genuinely as valuable as a donation — often more so. See the [Manifesto](MANIFESTO.md) for what kind of scrutiny and contribution this project is built to welcome.
