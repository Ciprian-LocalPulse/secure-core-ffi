THE PROMISE

Crypto logic once.
Integration everywhere.

Keep the sensitive primitive in one focused, testable Rust implementation. Let each application use the interface it already understands.

01

Small surface

A focused authenticated-encryption API with explicit pointer, length and ownership contracts at the FFI boundary.

02

Portable by design

Native libraries for Linux, Windows and macOS, plus a WebAssembly target for browser and Next.js experiments.

03

Honest primitives

Built for encryption of already-managed keys. Key derivation, rotation and application policy remain explicit responsibilities.
