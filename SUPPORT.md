# Support

## Where to ask

- Usage and integration questions: open a GitHub Discussion or Issue with the target platform, package version, operating system, and a minimal non-sensitive example.
- Bugs: open a GitHub Issue with reproduction steps and expected versus actual behavior.
- Security vulnerabilities: use GitHub Security Advisories as described in [SECURITY.md](SECURITY.md). Do not post vulnerabilities publicly.

## Response expectations

This is a community-maintained developer project. Best-effort responses are provided for public usage questions. No service-level agreement, managed key service, or emergency support channel is offered.

## Information never to include

Never include encryption keys, access tokens, production ciphertext containing sensitive data, customer records, or complete environment dumps in public reports.
